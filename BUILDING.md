# Android build

The build is pinned for reproducibility on Linux:

- Java 17;
- Python 3.11 or newer for Buildozer;
- Buildozer 1.6.0 and Cython 0.29.34;
- python-for-android commit `58d21141f17c889bf8585f5665921d72028f8831`;
- Android API 33, minimum API 21, NDK r25b;
- `arm64-v8a` and `armeabi-v7a` APK architectures.

Install the host dependencies listed in the GitHub Actions workflow, activate a
Python virtual environment, and run:

```bash
python -m pip install "buildozer==1.6.0" "Cython==0.29.34" "setuptools<81"
scripts/build_android.sh
```

The APK is written to `bin/`. Build caches, APK files, virtual environments,
and generated bytecode are intentionally excluded from Git.

The local recipes package dependencies that do not provide suitable Android or
Python 3.14 wheels. HTTP helper extensions use their portable Python
implementations; this favors compatibility over maximum HTTP throughput.
