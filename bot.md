### ⚠️ Главный нюанс: Bot API vs MTProto
Обычный **Telegram Bot** (которого вы создаете через @BotFather) **не умеет** читать сообщения в каналах, если он не добавлен туда как *администратор*. Если каналы чужие — стандартный бот не подойдет.

**Решение:** Тебе нужно использовать **MTProto API** (клиентские библиотеки). Они позволяют авторизоваться под своим аккаунтом (или выделенным номером) и слушать любые каналы, на которые ты подписан. 
Самая удобная библиотека для этого на Python — **Telethon** (или Pyrogram).

Ниже пошаговая инструкция, как это сделать с помощью Telethon.

---

### Шаг 1. Получение API ID и API Hash
Так как мы будем использовать клиентское подключение, тебе нужно получить ключи доступа:
1. Зайди на сайт [my.telegram.org](https://my.telegram.org/) и авторизуйся по номеру телефона.
2. Перейди в раздел **API development tools**.
3. Заполни форму (название и короткое имя приложения могут быть любыми).
4. Ты получишь **api_id** (число) и **api_hash** (строка). Сохрани их, они понадобятся в коде.

### Шаг 2. Установка библиотек
Тебе понадобится Python. Установи Telethon через терминал:
```bash
pip install telethon
```

### Шаг 3. Написание кода
Создай файл `monitor.py` и напиши следующий код:

```python
import asyncio
from telethon import TelegramClient, events

# Твои данные из my.telegram.org
api_id = 12345678               # Замени на свой api_id
api_hash = '0123456789abcdef'   # Замени на свой api_hash
phone = '+79991234567'          # Твой номер телефона (нужен для первой авторизации)

# Список каналов, которые слушаем (юзернеймы без @ или числовые ID)
channels_to_watch = ['channel1', 'channel2', 'channel3']

# Фраза, которую ищем
target_phrase = 'нужная фраза'

# Создаем сессию клиента (файл monitor.session сохранит авторизацию)
client = TelegramClient('monitor_session', api_id, api_hash)

@client.on(events.NewMessage(chats=channels_to_watch))
async def handler(event):
    # Получаем текст сообщения (включая подписи к картинкам/видео)
    text = event.message.message 
    
    if text and target_phrase.lower() in text.lower():
        # Формируем ссылку на сообщение (работает для публичных каналов)
        if event.chat.username:
            link = f"https://t.me/{event.chat.username}/{event.message.id}"
        else:
            link = "Ссылка недоступна (канал частный)"
            
        alert_text = (
            f"🚨 <b>Найдено совпадение!</b>\n\n"
            f"📢 <b>Канал:</b> {event.chat.title}\n"
            f"📝 <b>Текст:</b> {text}\n"
            f"🔗 <b>Ссылка:</b> {link}"
        )
        
        # Отправляем уведомление тебе в "Избранное" (Saved Messages)
        await client.send_message('me', alert_text, parse_mode='html')
        print(f"Совпадение в {event.chat.title}!")

async def main():
    # При первом запуске запросит номер телефона и код из Telegram
    await client.start(phone) 
    print("✅ Мониторинг запущен. Слушаю каналы...")
    
    # Держим скрипт запущенным
    await client.run_until_disconnected()

if __name__ == '__main__':
    asyncio.run(main())
```

### Шаг 4. Первый запуск
1. Запусти скрипт: `python monitor.py`.
2. При первом запуске Telethon попросит ввести номер телефона, а затем **код подтверждения**, который придет тебе в Telegram (или в приложение Telegram на телефоне).
3. После успешного входа создастся файл `monitor_session.session`. **Никому его не передавай**, он дает полный доступ к твоему аккаунту.
4. Теперь, если в указанных каналах появится фраза, бот пришлет тебе сообщение в раздел «Избранное» (Saved Messages).

### 💡 Полезные советы по улучшению

1. **Поиск по сложным условиям (Регулярные выражения):**
   Если тебе нужно искать не просто точное совпадение, а, например, "слово1" И "слово2", или числа, используй библиотеку `re`:
   ```python
   import re
   pattern = re.compile(r'ошибка\s+\d{4}', re.IGNORECASE)
   
   if text and pattern.search(text):
       # ... код отправки уведомления
   ```

2. **Как сделать, чтобы бот работал 24/7:**
   Локальный компьютер придется держать включенным. Лучше всего арендовать самый дешевый VPS (виртуальный сервер) за ~100-200 рублей в месяц (Timeweb, Aeza, FirstVDS и др.).
   * Загрузи код на сервер.
   * Используй утилиту `screen` или `tmux`, чтобы скрипт не закрывался при отключении от сервера:
     ```bash
     screen -S telegram_monitor
     python monitor.py
     # Нажми Ctrl+A, затем D, чтобы свернуть сессию.
     ```
   * Либо настрой `systemd` сервис или используй `Docker`.

3. **Если ты Администратор этих каналов:**
   Если эти 3 канала принадлежат *тебе*, и ты хочешь использовать именно классического бота (через BotFather), то тебе нужно добавить бота в админы каналов и использовать библиотеку `aiogram` или `pyTelegramBotAPI`. Но для чтения *чужих* каналов метод с Telethon (описанный выше) — единственно верный.
