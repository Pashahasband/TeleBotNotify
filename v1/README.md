# Telegram Channel Monitor

Бот для мониторинга 3 Telegram-каналов на наличие определённой фразы.

## Что делает

- **Слушает 3 канала** через MTProto (Telethon)
- **Ищет заданную фразу** в каждом новом сообщении
- **Отправляет уведомление** через твоего бота, когда находит совпадение

## Установка

### 1. Установи зависимости

```bash
pip install -r requirements.txt
```

### 2. Настрой config.py

Открой `config.py` и заполни:

```python
# MTProto (для чтения каналов)
TELETHON_API_ID = 12345678          # Смотри ниже
TELETHON_API_HASH = '...'           # Смотри ниже
TELETHON_PHONE = '+79991234567'     # Твой номер

# Bot API (для уведомлений)
BOT_TOKEN = '123456789:ABCdef...'   # От @BotFather

# Мониторинг
CHANNELS_TO_WATCH = [
    'channel1',  # Юзернеймы каналов БЕЗ @
    'channel2',
    'channel3',
]

TARGET_PHRASE = 'нужная фраза'      # Фраза для поиска
```

### 3. Получи API ID и Hash

1. Зайди на [my.telegram.org](https://my.telegram.org)
2. Авторизуйся по номеру телефона
3. Перейди в **API development tools**
4. Заполни форму (название/описание любые)
5. Скопируй `api_id` и `api_hash`

### 4. Создай бота

1. Напиши @BotFather в Telegram
2. Отправь `/newbot`
3. Придумай имя и юзернейм (должен заканчиваться на `bot`)
4. Скопируй токен и вставь в `config.BOT_TOKEN`

### 5. Запусти

```bash
python monitor.py
```

**Первый запуск:**
- Telethon попросит номер телефона и код подтверждения
- После входа создастся файл `monitor_session.session` — **храни его в секрете!**

### 6. Активируй бота

1. Найди своего бота в Telegram
2. Отправь `/start`
3. Бот сохранит твой ID и начнёт присылать уведомления

## Как это работает

```
Новое сообщение в канале
        ↓
Telethon перехватывает (MTProto)
        ↓
Проверка на целевую фразу
        ↓
Если найдено → aiogram отправляет уведомление тебе
```

## Безопасность

⚠️ **Никому не передавай:**
- Файл `.session` = полный доступ к аккаунту
- `BOT_TOKEN` = контроль над ботом
- `API_HASH` = возможность авторизации

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| `Unauthorized` | Проверь API ID/Hash и номер телефона |
| `Chat not found` | Проверь юзернеймы каналов (без @) |
| Бот не шлёт уведомления | Отправь `/start` боту в Telegram |
| `FloodControlError` | Подожди пару минут, Telegram ограничивает запросы |
